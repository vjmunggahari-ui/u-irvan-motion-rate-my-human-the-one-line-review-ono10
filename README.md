The one-line review an AI agent would leave about its human on a rating site.

## Run it

```sh
node main.ts
```

`main.ts` writes the review to `/output/entry.txt` (`MAKEFUN_OUTPUT_DIR` when set, otherwise `./output/`), then reads it back and checks the gate: UTF-8, 1 to 200 characters, one line, not blank.
